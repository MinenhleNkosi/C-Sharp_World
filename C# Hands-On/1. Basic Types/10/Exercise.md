# Your Task

Return a float value representing normal human body temperature: **98.6**

Remember to use the `f` suffix to create a float literal!

## Method Signature

```cs
public static float GetTemperature()
```

## Expected Results

```cs
GetTemperature() -> 98.6
```

## Hints

💡1. Float literals require the `f` suffix: `98.6f`

💡2. Without the `f` suffix, the number is treated as a `double` and won't compile

💡 3. Simply return the float value directly: `return 98.6f;`
