# Your Task

Complete four methods:

- `GetAge()` - Declare an int variable `age` set to 25, return it
- `GetYear()` - Declare an int variable `year` set to 2024, return it
- `GetTemperature()` - Declare an int variable `temperature` set to -5, return it
- `AddNumbers(int a, int b)` - Return the sum of the two parameters

## Method Signatures

```cs
public static int GetAge()
public static int GetYear()
public static int GetTemperature()
public static int AddNumbers(int a, int b)
```

## Expected Results

```cs
Age() -> 25
GetYear() -> 2024
GetTemperature() -> -5
AddNumbers(10, 5) -> 15
```

## Hints

💡 1. To declare an int variable: `int variableName = value;`

💡 2. Negative numbers use a minus sign: `int temp = -5;`

💡 3. Use the `return` keyword to send a value back from a method
