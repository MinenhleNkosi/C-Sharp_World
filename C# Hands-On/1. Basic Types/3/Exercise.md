# Your Task

Create a string variable called `greeting` with the value `"Hello, World!"` and print it to the console.

## Method Signature

```cs
public static void PrintGreeting()
```

## Expected Output

```cs
Hello, World!
```

## Hints

💡 1. Use the `string` keyword to declare a string variable

💡 2. String values must be enclosed in double quotes like `"Hello, World!"`

💡 3. Use `Console.WriteLine(variableName)` to print the value of your variable
