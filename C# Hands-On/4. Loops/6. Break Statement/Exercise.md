## Method Signature

```cs
public static void FindFirstDivisibleBySeven()
```

## Expected Results

```cs
FindFirstDivisibleBySeven() prints: 7
```

- Use the modulo operator `%` to check divisibility: `i % 7 == 0` means i is divisible by 7
- Once you find and print the number, use `break;` to exit the loop immediately
