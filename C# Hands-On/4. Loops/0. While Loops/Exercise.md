# Your Task

Write a method that uses a while loop to print the numbers 1 through 5, each on a new line.

## Method Signature

```cs
public static void PrintNumbers()
```

## Expected Output

```
1
2
3
4
5
```

## Hints

- Start by declaring a counter variable and initializing it to `1`.
- Your while condition should check if the counter is `<= 5`.
- Don't forget to increment your counter with `++` inside the loop to avoid an infinite loop.
