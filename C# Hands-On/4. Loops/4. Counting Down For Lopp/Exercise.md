# Your Task

Write a method that prints a countdown from 5 to 1. Each number should be printed on its own line.

## Method Signature

```cs
public static void Countdown()
```

## Expected Output

```
5
4
3
2
1
```

## Hints

- Start your loop variable `i` at `5` instead of `1`
- Use `i--` to decrease the value each iteration instead of `i++`
- Your condition should be `i >= 1` to stop after printing `1`

## Code Format Example

```cs
using System;

public class Solution
{
    public static void Countdown()
    {
        // Your code here
        // Print numbers from 5 down to 1, each on a new line
    }
}
```
