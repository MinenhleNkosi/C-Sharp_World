# Your Task

Implement a method that divides the first number by the second number and returns the result.

## Method Signature

```cs
public static double Divide(double a, double b)
```

## Expected Results

```cs
Divide(10.0, 2.0) -> 5.0
Divide(7.0, 2.0) -> 3.5
Divide(15.0, 4.0) -> 3.75
```

## Hints

- Use the `/` operator to divide `a` by `b`
- The result should be returned directly - no rounding needed
- Remember: `a / b` gives you the quotient of a divided by b
