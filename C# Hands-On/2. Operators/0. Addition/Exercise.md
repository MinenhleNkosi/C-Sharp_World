# Your Task

Create a method that takes two integers and returns their sum using the `+` operator.

## Method Signature

```cs
public static int Add(int a, int b)
```

## Expected Results

```cs
Add(2, 3) -> 5
Add(10, 20) -> 30
Add(-5, 5) -> 0
```

## Hints

- Use the `+` operator between the two parameters
- The `return` keyword sends the result back to the caller
- You can add the values directly in the return statement: `return a + b;`
