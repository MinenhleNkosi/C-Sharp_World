# Your Task

Implement a method that subtracts the second number from the first and returns the result.

## Method Signature

```cs
public static int Subtract(int a, int b)
```

## Expected Results

```cs
Subtract(10, 3) -> 7
Subtract(5, 5) -> 0
Subtract(3, 10) -> -7
```

## Hints

- Use the `-` operator to subtract two numbers
- The operation is `a - b`, which subtracts `b` from `a`
- Remember that the result can be negative if `b` is larger than `a`
