# Your Task

Implement the `Multiply` method that takes two integers and returns their product using the `*` operator.

## Method Signature

```cs
public static int Multiply(int a, int b)
```

## Expected Results

```cs
Multiply(3, 4) -> 12
Multiply(7, 8) -> 56
Multiply(5, 0) -> 0
```

## Hints

- Use the `*` operator to multiply two numbers together
- The syntax is similar to addition and subtraction: `a * b`
- Remember to return the result of the multiplication
