# Your Task

Implement a method that returns the remainder when dividing the dividend by the divisor.

## Method Signature

```cs
public static int GetRemainder(int dividend, int divisor)
```

## Expected Results

```cs
GetRemainder(17, 5) -> 2
GetRemainder(10, 3) -> 1
GetRemainder(20, 4) -> 0
```

## Hints

- The modulo operator in C# is the percent sign: `%`
- Think of modulo as "what's left over" after division
- The pattern is: `dividend % divisor`
