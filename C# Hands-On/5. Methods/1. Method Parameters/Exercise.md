# Your Task

Create a method called `PrintSum` that takes two integer parameters `a` and `b`, and prints their sum to the console. Then, call this method from the `Main` method with the values `5` and `3`.

## Method Signature

```cs
public static void PrintSum(int a, int b)
```

## Expected Results

```cs
PrintSum(5, 3) prints: 8
PrintSum(10, 20) prints: 30
PrintSum(-5, 5) prints: 0
```

## Hints

- Use the `+` operator to add the two parameters together
- Use `Console.WriteLine()` to print the result of `a + b`
- In `Main`, call `PrintSum(5, 3);` to invoke your method with the required arguments
