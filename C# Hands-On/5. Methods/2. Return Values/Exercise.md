# Your Task

Create a method called `Square` that takes an integer and returns its square (the number multiplied by itself).

## Method Signature

```cs
public static int Square(int number)
```

## Expected Results

```cs
Square(2) -> 4
Square(5) -> 25
Square(-3) -> 9
```

## Hints

- To square a number, multiply it by itself: `number * number`
- Use the `return` keyword followed by the expression you want to send back
- The return type `int` means your method must return an integer value
